# Exein Homebrew Tools

Homebrew tap for command-line tools published by [Exein](https://www.exein.io/).
Works on macOS and Linux.

## Install

Install any tool directly by fully-qualified name:

```bash
brew install exein-io/tools/<formula>
```

Or tap first, then install by short name:

```bash
brew tap exein-io/tools
brew install <formula>
```

## Available formulae

| Formula    | Description                                                                                       |
|------------|---------------------------------------------------------------------------------------------------|
| `analyzer` | CLI for [Exein Analyzer](https://www.exein.io/) — firmware and container security scanning.       |

## Updating

```bash
brew update
brew upgrade <formula>
```
